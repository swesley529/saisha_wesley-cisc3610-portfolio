Project Structure

All files are located in the pages folder of the repository:

  • pwaproject.html — main app page
  • pwaapp.js — JavaScript logic
  • pwastyle.css — all styling
  • pwadata.json — topic data
  • pwamanifest.json — PWA manifest
  • pwaserviceworker.js — offline caching
  • pwapromopage.html — promotional page
  • pwadocs.html — user documentation
  • pwaprogrammerdocs.html — programmer documentation

How the JSON Works

All topic content is stored in pwadata.json. The app reads this file and automatically builds the nav links and cards. Each topic has 4 fields:

  • title — the topic name shown on the card and nav
  • description — the text shown on the card
  • image — the image filename
  • audio — the audio filename

How to Add a New Topic

To add a new topic, open pwadata.json and add a new object inside the wellness array. Follow this format:

{ "title": "Sleep", "description": "Getting enough sleep is essential for your mental and physical health. Aim for 7-9 hours per night.", "image": "sleep.png", "audio": "sleep.mp3" }

Make sure to add a comma after the previous topic's closing bracket before adding your new one. For example:

{ "wellness": [ { "title": "Meditation", ... }, { "title": "Sleep", "description": "Your description here.", "image": "sleep.png", "audio": "sleep.mp3" } ] }

Adding the Image and Audio Files

  1. Add your image file (png or jpg) to the same folder as the HTML file
  2. Add your audio file (mp3) to the same folder
  3. Make sure the filenames in the JSON exactly match the actual filenames
  4. Add both filenames to the FILES_TO_CACHE array in pwaserviceworker.js so they work offline

Updating the Service Worker Cache

Whenever you add new files, open pwaserviceworker.js and add them to the FILES_TO_CACHE array:

const FILES_TO_CACHE = [ 'pwaproject.html', 'pwadata.json', ... 'sleep.png', 'sleep.mp3' ];

Also update the cache name to force the browser to reload the new version:

const CACHE_NAME = 'wellnessguide-v2';
